Práctica 2

Introducción

En esta práctica analizamos cómo detectar software sospechoso y qué medidas pueden aplicarse para evitar la ejecución de programas no autorizados en entornos corporativos.

Capturas de pantalla

Análisis y conclusiones

1. Un ejecutable puede ser sospechoso si proviene de fuentes no oficiales, imita procesos del sistema o pide permisos elevados sin motivo.
2. Las organizaciones pueden aplicar listas blancas, limitar privilegios y usar soluciones EDR o antivirus para bloquear software no autorizado.
3. La ingeniería social facilita estos ataques cuando el archivo parece provenir de una entidad confiable.
4. El acceso físico incrementa el riesgo al permitir instalar software o modificar configuraciones directamente.
