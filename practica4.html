Cracking de Hash SHA-256

Introducción

En esta práctica se intenta descubrir una contraseña a partir de un hash SHA-256. Para ello se usa un script en Python que genera combinaciones de letras, calcula su hash y lo compara con el hash almacenado en hash_guardado.txt.

Código utilizado


import hashlib
import itertools
import string
import time

with open("hash_guardado.txt","r") as archivo:
    hash_objetivo = archivo.read().strip()

print("Hash objetivo:", hash_objetivo)

letras = string.ascii_lowercase

intentos = 0
inicio = time.time()

for longitud in range(1,5):
    for combinacion in itertools.product(letras, repeat=longitud):

        password = ''.join(combinacion)
        intentos += 1

        hash_calculado = hashlib.sha256(password.encode()).hexdigest()

        if hash_calculado == hash_objetivo:
            fin = time.time()

            print("\nCONTRASEÑA ENCONTRADA")
            print("Contraseña:", password)
            print("Intentos:", intentos)
            print("Tiempo:", round(fin - inicio,4),"segundos")
            exit()

print("No se encontró la contraseña")
